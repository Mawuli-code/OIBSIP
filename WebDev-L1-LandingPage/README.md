Savanna Table — Restaurant Landing Page

A modern, responsive restaurant landing page built as part of the Oasis Infobyte Internship Program (OIBSIP) — Web Development Track, Level 1, Task 1.

Savanna Table is a fictional African-inspired restaurant created to demonstrate foundational HTML5 and CSS3 web development skills while applying modern responsive web design principles.

Project Overview

Savanna Table is designed around the concept of a modern African restaurant that combines traditional flavours with contemporary presentation.

The landing page provides visitors with information about the restaurant, highlights signature dishes, introduces the restaurant's story, and provides clear calls to action for exploring the menu and making a reservation.

The design uses a warm, elegant colour palette inspired by African landscapes and food culture, combined with modern typography and responsive layouts.

Responsive Design

The website was designed and tested across multiple screen sizes.

Desktop / Laptop

The desktop layout uses multi-column sections for the hero, signature dishes, story, and restaurant features.

Tablet

The layout adapts to a smaller screen by reducing the number of columns and adjusting spacing.

Mobile

The mobile layout uses a single-column structure to ensure readability and prevent content overlap.

The mobile navigation intentionally removes the desktop reservation button to prevent overcrowding on smaller screens while keeping the main reservation CTA available within the page.
