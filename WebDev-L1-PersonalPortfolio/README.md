Personal Portfolio – Bright Avorklayi

A responsive personal portfolio website showcasing my skills, professional experience, certifications, projects, and contact information.

Overview

This project is a personal portfolio website developed to present my background and technical skills as an aspiring Software Engineer and Web Developer.

The website provides a clean and responsive interface where visitors can learn about my experience, explore my technical skills and projects, view professional certifications, and find ways to contact me.

Features

1.Responsive personal portfolio design
2.Sticky navigation bar
3.Smooth scrolling between sections
4.Hero section with profile image and professional introduction
5.About Me section
6.Technical Skills section
7.Professional Experience section
8.Certifications section with credential links
9.Projects section
10.Contact section with email, LinkedIn, GitHub, and WhatsApp
11.Hover animations and interactive UI elements
12.Mobile, tablet, and desktop responsive layouts

Technologies Used

1.HTML5 – Structure and semantic organization of the website
2.CSS3 – Styling, layouts, animations, and responsive design
3.Font Awesome – Icons used throughout the portfolio
4.Git & GitHub – Version control and project hosting

Getting Started

To run the portfolio locally:

1. Clone the repository.

bash
git clone https://github.com/mawuli-code/OIBSIP.git


2. Navigate to the PersonalPortfolio project folder.

bash
cd OIBSIP


3. Open 'index.html' in your preferred web browser.

Alternatively, you can use Visual Studio Code with the Live Server extension to launch the website locally.
